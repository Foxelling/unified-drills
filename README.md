# Unified Drills

A utility mod that links adjacent drills into a shared logistics and cooling network.

## Features
* **Item Chaining:** Adjacent drills automatically pass mined items to each other, moving resources down the line until they find an available conveyor or core.
* **Liquid Sharing:** Connect a water or cryofluid pipe to just one drill, and it will automatically distribute excess coolant to all neighboring drills.
* **Universal Compatibility:** Injects logic via JavaScript at runtime, meaning it dynamically patches all vanilla drills and any custom drills added by other mods.
